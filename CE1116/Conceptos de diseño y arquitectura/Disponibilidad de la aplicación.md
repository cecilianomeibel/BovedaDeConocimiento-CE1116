## 📚 Idea/Concepto 
Es la capacidad de un sistema de software para estar operativo y accesible cuando los usuarios lo necesitan, considerando tanto tiempos de inactividad planificados como no planificados. Se mide generalmente como un porcentaje de tiempo activo (ej. 99,9%) y se monitorea mediante métricas de rendimiento y solicitudes exitosas. Para garantizarla, se aplican estrategias de resiliencia como redundancia, failover y recuperación ante desastres, y se define en acuerdos de nivel de servicio (SLA) que establecen expectativas claras de funcionamiento
